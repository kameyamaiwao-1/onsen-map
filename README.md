# 百名湯 制覇マップ

松田忠徳『日本百名湯』と『新・日本百名湯』を地図に表示し、入湯した年を記録するWebページです。

```
GitHub Pages（このリポジトリ）── 地図ページと温泉マスタ（公開情報のみ）
        │ POST（合言葉つき）
        ↓
Google Apps Script ── Googleスプレッドシート「入湯記録」（非公開・本人のDrive）
```

- 入湯記録はスプレッドシートにだけ保存され、GitHubには載りません。
- 同期を設定しなくても動きます。その場合、記録はその端末のブラウザにだけ保存されます。

## ファイル

| パス | 内容 |
|---|---|
| `index.html` | 地図ページ（Leaflet＋地理院タイル） |
| `data/onsen.json` | 温泉マスタ。`lists` に `hyaku`（百名湯）と `shin`（新百名湯）を持つ |
| `data/hyakumeito_raw.csv` | 百名湯100件の原リスト（Wikipedia「日本百名湯」）。2026-11-25に書籍の目次と照合し、収録100湯の一致を確認。`onsen.json` の名称は書籍の表記に合わせた |
| `data/geocoded.csv` | 座標の取得結果。`manual` は温泉地の代表点を手入力したもの |
| `gas/Code.gs` | 入湯記録の読み書きAPI（Apps Scriptに貼り付ける） |

## GAS（同期）の設定手順：初回のみ・約5分

1. Googleドライブで新しいスプレッドシートを作る（名前の例：`温泉入湯記録`）
2. メニュー「拡張機能 → Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消し、`gas/Code.gs` の内容を貼り付けて保存する
4. 上の関数選択で `setup` を選び「実行」を押す。権限の確認が出たら自分のアカウントで許可する
   - 「このアプリは Google で確認されていません」と出た場合は「詳細 → （安全ではないページ）に移動」を押す。自分で書いたスクリプトなので問題ない
5. 「実行ログ」に出た **合言葉** を控える（スプレッドシートに「入湯記録」シートもできている）
6. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（合言葉がないと読み書きできないので、記録は守られる）
7. 発行された **ウェブアプリURL**（`https://script.google.com/macros/s/…/exec`）を控える
8. 地図ページの「設定」に URL と合言葉を入れて「保存して接続」を押す。Macとスマホの両方で1回ずつ行う

コードを直したときは「デプロイを管理 → 編集 → 新バージョン」で更新する（URLは変わらない）。

## 新・日本百名湯の追加

新・日本百名湯（NIKKEIプラス1連載 2002-10〜2004-09）は、2026-11-25に書籍の目次写真から書き起こした（`data/shin_raw.csv`、座標は `data/shin_geocoded.csv`）。百名湯との重複19湯は既存項目に `"shin"` を付与し、新規81湯を `S001`〜`S081` とした。以後の追加・修正は次の規則で行う。

- 百名湯と重複する温泉は、既存の項目の `lists` に `"shin"` を足す（`["hyaku","shin"]`）
- 新規の温泉は `id` を `S001` 以降で採番し、`lists: ["shin"]` にする

## 座標について

100件中78件は OpenStreetMap で取得し、残り22件は温泉地の代表点を手入力しました。全件、地理院の逆ジオコーダで都道府県が一致することを確認しています。宿の位置とは数km程度ずれる場合があります。
